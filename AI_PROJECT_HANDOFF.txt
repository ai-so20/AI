사용자가 "이어서 진행", "다음"이라고 하면 현재 작업 다음 단계부터 실제 코드 수정 → Vercel 배포 확인 → 짧은 결과 보고까지 수행한다.
기존 26, 기존 Supabase 데이터를 무단으로 수정하거나 두 프로젝트를 합치면 안 된다.
수정 전에 GitHub HEAD / 현재 배포 상태 / 관련 원본 소스를 확인한다. 본 문서는 인수인계 기록이지, 실제 현재 상태의 영구적인 대체 자료는 아니다.

[사용자 업무/대화 원칙]

- GitHub 반영, Vercel READY, 실제 회원 계정으로 기능 성공은 별개의 검증 단계. 검증하지 않은 성공을 주장하지 않는다.
- 원본 기능 및 데이터 계약 유지. 기존 코드/CSS/디자인을 무비판적으로 복제하는 것이 아니라 기능/구성/내용을 이식한다.
- 디자인은 사용자가 전체 이식 종료 후 한 번에 검토할 예정. 지금 디자인 감상평, 구조 전체 리뉴얼, 임의 디자인 변경 금지.
- 특히 홈은 하단 '주식·코인' 부분만 개선 대상. 그 외 홈 부분은 이식 완료 후 사용자 검토까지 건드리지 않는다. 홈 숫자가 시안 값인 점은 파악했으나 지금 임의 변경하지 않는다.

[C. 이벤트: 데이터/참여/결과]
app/design-event/page.js.
원본과 같은 RPC get_auto_events, join_auto_event 사용.
SQL 함수 확인 결과 get_auto_events는 한국시간 당일 자동이벤트만 반환한다:
event_id,title,description,prize,event_type,status,starts_at,ends_at,round_number,
participated,winner_nickname,my_answer,my_result_text,quiz_question,
quiz_option_1~4,revealed_answer.
join_auto_event는 JSON {success, message, ...}를 반환하므로 error=null만으로 성공 판정하면 안 된다.
성공=false의 정상 반환을 실패로 표기하도록 수정.
숫자 범위는 DB 함수 기준 1~100 (이전 1~10 수정이 잘못되었으므로 되돌림).
퀴즈/선물상자는 1~4, 룰렛/선착순/추첨 등 유형 처리 연결.
이벤트 상품명 필드는 prize (prize_name 아님).
회차/시각/상품명/설명/참여 결과/공개 정답/당첨자 표시 연결.
최근 당첨은 group_messages의 기존 '🎉 VIP EVENT · 당첨 안내' 공지 텍스트를 회원 권한으로 읽어 파싱해 표시. 읽기 권한(RLS)이 없거나 조회 실패면 당일 이벤트의 winner_nickname 기반으로 일부 표시.
원본 DB 조회에서 group_messages 누적 당첨 공지가 존재함을 확인했으나 실제 회원 브라우저에서 완전 검증은 아직 안 함.
대표 최종 커밋: 9687b218f4a32dbef842d637d3d9d9ff90bdaf77
이 커밋 Vercel READY 확인.
주의: 화면의 '오늘 내 당첨'은 당일 자동이벤트 RPC 범위에서 계산. 과거 당첨 공지와 같은 의미가 아님.
상품 이미지는 현재 RPC 및 events 테이블에 직접 이미지 URL 필드가 없어서 미이식. 이미지 경로를 임의 생성하면 안 된다. 운영 중 실제 이미지 관리 경로를 원본과 추가 확인해야 한다.

  - 신규 AI 코드만 수정 → Vercel READY 확인.
2순위: 상품지급센터의 원본 기능 누락(관리자 답변, 푸시 알림, 상품 링크/이미지, 읽음, 지급 상세), 권한/라우팅 검증.

5순위: 홈 하단 주식·코인 부분이 원본 콘텐츠/상태/가격과 정확히 연결되는지 점검 및 수정. 홈 그 외 영역은 지금 건드리지 않음.
6순위: 메뉴/로그인 통합. 일부 신규 출석/상품 지급 페이지의 이벤트 링크가 /?tab=event 등 기존 URL로 남아 있음; /design-event로 정리 여부는 전체 동선 기준 검증.
7순위: 관리자 기능을 새 UI에 어떻게 연결할지 원본과 비교. 기존 원본 관리자 기능 보존, 승인 없이 재설계·데이터 수정 금지.
8순위: 전체 이식 종료 후 실제 계정으로 기능 검증·원본과 화면 값 비교. 그 후 사용자가 디자인을 일괄 검수.
