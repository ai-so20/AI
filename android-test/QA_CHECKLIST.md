# AI 프로세스 Android 사용자 테스트 체크리스트

원칙: 통과/실패는 실제 테스트 후에만 기록합니다. APK 컴파일과 수동 기능 검증은 서로 다릅니다.

| 순서 | 구간 | 확인 내용 | 기대 결과 |
|---|---|---|---|
| 1 | 설치 | 기존 앱 위에 APK 설치 | 덮어쓰기 가능 또는 충돌 원인 안내 |
| 2 | 첫 실행 | 비로그인 상태의 앱 실행 | 회원 로그인 화면 |
| 3 | 인증 | 승인된 테스트 계정 로그인 | 홈 진입, 회원 정보 표시 |
| 4 | 인증 | 틀린 비밀번호 | 오류 안내, 로그인 우회 없음 |
| 5 | 세션 | 종료·강제 종료 후 재실행 | 세션 유효 시 자동 로그인, 만료 시 로그인 화면 |
| 6 | 세션 | 로그아웃 및 앱 재실행 | 회원 정보 노출 없이 로그인 화면 |
| 7 | 이동 | 홈 → 이벤트 → 홈 | 화면 전환·메뉴 활성 상태 정상 |
| 8 | 이동 | 홈 → 출석 → 홈 | 화면 전환 및 데이터 보존 |
| 9 | 이동 | 홈 → AI PROCESS → 홈 | 실제 상태·데이터 정상 |
| 10 | 이동 | 홈 → 상품 지급 센터 → 홈 | 상태 및 데이터 정상 |
| 11 | 뒤로 | 하위 페이지에서 시스템 뒤로 가기 | 이전 경로로 돌아가기 |
| 12 | 뒤로 | 루트 홈에서 뒤로 가기 2회 | 안내 후 종료 |
| 13 | 키보드 | 로그인 닉네임/비밀번호 포커스 | 키보드가 입력란·로그인 버튼을 가리지 않음 |
| 14 | 키보드 | 키보드 열린 상태에서 뒤로 가기 | 키보드 우선 닫힘 |
| 15 | 네트워크 | 앱 시작 시 인터넷 끄기 | 내장 연결 오류 화면 표시 |
| 16 | 네트워크 | 연결 복구 뒤 다시 연결하기 | 로그인 또는 유지된 세션에 따른 정상 화면 |
| 17 | 네트워크 | 화면 이동 중 연결 끊김 | 안전한 오류 표시, 유저 데이터 변경 없음 |
| 18 | 연동 | 이벤트/출석 데이터 재조회 | 운영 웹과 동일한 기록, 중복 실행 없음 |
| 19 | 앱 전환 | 다른 앱으로 전환 후 복귀 | 페이지/로그인 상태 유지 |
| 20 | 보안 | 관리자 승인 안 된 계정 | 승인 전 접근 불가 |
| 21 | 화면 | 320/390/440px 기기 및 가로/세로 | 가로 스크롤·화면 잘림 없음 |
| 22 | 외부 링크 | 외부 URL 탭 | 기존 외부 브라우저 정책 적용 |
| 23 | 장시간 | 앱 10분 사용 후 화면 이동 | 앱 프로세스 및 주요 기능 안정성 |
| 24 | 데이터 | 계정, 로그인 기록, 재접속 | 사용 내역/데이터가 기존 운영 사이트와 동일 |

자동 검사 범위: Capacitor 빌드, AndroidManifest, Android Java 소스 컴파일, APK 설치, 앱 프로세스 유지, 화면 PNG 캡처.
수동 확인이 필요한 항목: 로그인 성공/실패, 이벤트·출석, 키보드 가림, 네트워크 끊김 실제 UI, 보안/로그아웃, 장시간 안정성.

추가 집중 검수: 홈 상단 `로그아웃` 버튼 표시 → 누르면 로그인으로 이동 → 앱 종료·재실행 시 자동 로그인되지 않음 → 다른 테스트 계정으로 로그인 가능. 이 4개는 실기기 검증 후에만 통과로 판정.
